
#  Student Intelligence Dashboard (SID)

A terminal-based Python application to manage and track student academic records with auto-generated IDs, performance scoring, file-based storage, and clean reporting.

---

##  Features

- Add student records with unique Student IDs
- Calculate average scores and generate remarks
- Store data in JSON and CSV formats
- Search, update, and delete student entries
- Generate report cards in TXT format
- Modular code design with helper functions in `utils.py`

---

##  Technologies Used

- Python 3
- Built-in modules: `json`, `csv`, `datetime`, `os`

---

```
├── README.md                         # This file
```

## How to Run

1. Download or clone the repo
2. Run:
```bash
python student grade tracker (lite).py
```
3. Follow on-screen prompts to manage students
